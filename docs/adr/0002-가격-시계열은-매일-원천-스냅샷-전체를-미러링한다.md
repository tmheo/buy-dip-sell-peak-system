# 가격 시계열은 매일 원천 스냅샷 전체를 미러링한다

Yahoo Finance는 배당·분할이 발생하면 과거 전체 `adjClose`를 소급 조정하지만, 증분 적재 + 충돌 무시 삽입 구조는 이를 반영하지 못해 배당락일마다 DB 시계열에 불연속이 쌓였다(이슈 #42 실측: TQQQ 전 구간 최대 0.4% 드리프트).
매매 규칙·지표·추천이 모두 `adjClose` 연속성을 불변식으로 삼으므로, 일일 동기화를 "전체 히스토리 재페치 + upsert" 미러링으로 전환하기로 결정했다.
Yahoo 요청 수는 증분 방식과 동일하게 티커당 1회라 추가 비용이 사실상 없고, 지표도 매일 전체 재계산해 자가 치유되게 한다.

## Considered Options

- 배당 이벤트 감지 후 선별 소급 갱신, 주기적 재정합: 같은 결과에 감지 장치와 별도 경로만 늘어나 기각.
- 증분 유지 + 드리프트 허용: 매매 규칙 통합이 확정한 연속성 불변식과 충돌해 기각.

## Consequences

- 분할 규모의 `close` 소급 변경(행 단위 5% 초과)은 자동 흡수하지 않는다.
  보유 포지션과의 무손실 정합은 SPEC-SPLIT-001 런북이 담당하므로, 동기화는 해당 티커 쓰기를 중단하고 알림만 낸다.
- 추천 기록은 소급 재계산하지 않는다(CONTEXT.md "추천 기록").
- 배당 규모(~0.2%)로 남는 보유 포지션 매도 목표가의 스케일 차이는 허용 오차로 받아들인다.
