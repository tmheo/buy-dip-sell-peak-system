# 사이클 중 실현 수익은 예수금에 포함하지 않는다

매매 규칙을 `src/strategy` 모듈로 통합하면서, 사이클 진행 중 티어 매도로 실현된 수익을 예수금(매수 여력)에 합산할지 결정해야 했다.
백테스트는 매도 대금 전액을 예수금에 넣어 같은 사이클의 예비 티어 매수까지 굴렸고, 실계좌는 원금만 회복시키고 수익은 사이클 종료까지 묶어 두었다.
실계좌 방식으로 통일한다: 예수금은 `사이클 자본 - Σ(활성 티어 투자원금)`이며, 실현 수익의 재투자는 사이클 경계에서만 일어난다.

이유는 리스크 통제다.
예비 티어까지 매수가 진행됐다는 것은 하락장일 가능성이 크다는 뜻인데, 그 시점에 실현 수익까지 얹어 매수 규모를 키우면 하락장에서 손실이 커진다.
수익률을 다소 양보하고 안정성을 얻는 의도된 선택이므로, 백테스트를 증권사 계좌의 실제 현금 흐름(매도 대금 즉시 가용)에 맞추자는 제안이 다시 나오면 이 문서를 근거로 판단할 것.

## Consequences

- 백테스트의 예비 티어 금액과 현금 부족 판정이 기존보다 보수적으로 바뀌어, 골든 값 회귀 테스트(`validation.test.ts`)의 기준선이 이동한다.
- 사이클 경계에서는 `사이클 자본 + Σ실현손익 = 기존 종료 현금`이므로 복리 이월 값은 변하지 않는다.
- 예수금이 순수 파생값이 되어 실계좌에 현금 상태를 따로 저장할 필요가 없다.
